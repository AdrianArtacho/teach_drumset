# 🥁 Virtual Drumset

A lightweight browser-based drum set built with **HTML, CSS, and JavaScript**.  
Click on the drums or play them from your **computer keyboard** to trigger sounds.  
Each key is mapped to a different drum part, and multiple **sound kits** can be loaded dynamically from the `/sounds` folder.

---

## 🚀 Demo & Hosting

You can open the app directly in your browser from GitHub Pages once deployed:

[virtual-drumset](https://adrianartacho.github.io/teach_drumset/drumset.html)

---

> 💡 You can also embed it elsewhere (for example in a WordPress site) using an `<iframe>`:

```html
<iframe
  src="https://<your-username>.github.io/<repo-name>/drumset.html"
  width="640"
  height="640"
  style="border:0;"
  allow="autoplay">
</iframe>
